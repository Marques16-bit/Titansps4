# Créditos

- **OpenOrbis** (toolchain GPL-3.0; bibliotecas sob termos próprios) e **PacBrew**: baixados no build pelo
  `scripts/fetch-pacbrew.sh`, não estão neste repositório.
- **DejaVu Sans Mono** (licença Bitstream Vera/DejaVu): os glifos de `app/src/font8x16.h` foram rasterizados dela.
- **Poppins** (SIL OFL 1.1): usada só para desenhar a capa (`icon0.png`, `pic1.png`).
